# CET-6 学习系统

一个可直接在浏览器打开、纯前端运行的六级备考工具。无需安装、无需联网、学习记录保存在本机。

## 打开方式

双击 `index.html` 即可（推荐 Chrome / Edge，听力朗读依赖浏览器语音合成）。

文件结构：

```
index.html      页面骨架
styles.css      全部样式
data-vocab.js   150 个六级高频词
data-content.js 听力 / 阅读 / 翻译 / 写作题库
data-exam.js    水平自测卷（30 题）
data-plan.js    八周备考路线（2026-12-12 考试）
data-memory.js  记忆方法、遗忘曲线与词根词缀数据
app.js          全部交互逻辑（含 SM-2 记忆引擎与提醒调度）
```

七个文件需放在同一目录。

## 十个模块

| 模块 | 内容 | 说明 |
| --- | --- | --- |
| 复习提醒 | 今日到期、14 天负载预测、手机提醒 | 三种提醒通道：应用内提示 / 系统通知 / 日历订阅 |
| 备考计划 | 8 周路线、分值拆解、每日时间表 | 按 2026-12-12 考试日倒排，自动标出本周与检查点 |
| 水平自测 | 30 题：词汇 12 / 语法 6 / 阅读 8 / 听力 4 | 交卷即出分，判定等级、找短板，生成可一键应用的学习计划 |
| 词汇训练 | 150 词，按主题标签分类 | 卡片翻转 + SM-2 间隔重复，四档评分决定下次复习日 |
| 记忆方法 | 遗忘曲线、8 种记忆法、42 组词根词缀 | 附个人记忆参数（易度、间隔、遗忘率）与算法说明 |
| 听力训练 | 3 组 × 4 题 | 浏览器语音合成朗读，可反复听；提交后展开原文与解析 |

| 学习数据 | 打卡热力图、词汇分布、正确率 | 自动统计，数据来自每次练习 |

## 备考计划怎么来的

2026 年下半年 CET-6 笔试在 **12 月 12 日（周六）15:00–17:25**（口试 11 月 22 日）。计划以考试日为锚点往前推八周：

| 周次 | 阶段 | 主题 |
| --- | --- | --- |
| W1–W2 | 基础重建 | 摸底、词汇 650、长难句、听力题型分化 |
| W3–W5 | 专项突破 | 阅读提速、选词填空、翻译成段、写作成篇、短板攻坚 |
| W6–W7 | 模考校准 | 每周 1–2 套全真限时，错题四类归因 |
| W8 | 考前收口 | 只看错题与模板，不做新题 |

页面会按当天日期判断「已过去 / 本周 / 未来」，本周高亮并给出直达练习的按钮。改设置里的考试日期，整张表会自动重排。

## 水平自测怎么算分

- 四个维度按权重合成：词汇 30%、语法 15%、阅读 35%、听力 20%
- 加权正确率线性折算到 710 分制（约 280 + 420 × 正确率），最低 300、最高 680
- 等级：`≥550` 冲刺高分 / `500–549` 稳步提分 / `425–499` 接近过线 / `<425` 基础待夯实
- 报告给出：估算分、四维正确率、优势项与最需补强项、六周三阶段计划、逐题解析
- 点「应用这套计划」会写入每日新词量与时长目标，首页任务和词汇队列随即按新目标执行

选项顺序在加载时会用固定种子打乱一次，正确答案均匀分布在 A/B/C/D，避免「全选 A」蒙分。

## 记忆算法（SM-2 间隔重复）

每次评分换算为质量分 q：忘记=2、模糊=3、记得=4、很熟练=5。

- **易度因子 EF**（初始 2.5，范围 1.3–3.0）：`EF ← EF + (0.1 − (5−q)(0.08 + (5−q)×0.02))`
- **间隔递推**：首次 1 天 → 第二次 6 天 → 之后 `I × EF`；「模糊」档额外 ×0.72 收敛，「很熟练」×1.12 加速；上限 180 天
- **遗忘重置**：q < 3 时间隔归 1 天，EF 下调，遗忘次数 +1，本组末尾再出现一次
- **记忆强度**：指数遗忘模型 `R = e^(−t/S)`，S 由当前间隔反推（到期日恰好剩 90%）；复习页展示每词留存率与整体记忆健康度
- **已掌握**：间隔 ≥ 21 天、连续答对 ≥ 4 次且遗忘 ≤ 2 次
- **队列**：到期词与新词按 2:1 交错排布（交错练习优于集中练习）

到期词按「先逾期、后留存率低」排序，最危险的词最先出现。

## 复习提醒（三种通道）

在「复习提醒」页设置每天最多三个提醒时间（默认 08:00 / 12:30 / 20:30）：

1. **应用内提醒**：打开应用即显示今日到期数量，不依赖任何权限
2. **系统通知**：授权后，页面到点弹系统通知；已安装到主屏（PWA）时安卓 Chrome 可通过 Background Periodic Sync 在后台唤醒检查，通知点击直达复习页
3. **日历提醒（最可靠）**：导出 `.ics` 文件导入手机日历，从明天起到考试日每天在设定时间由系统弹窗提醒，与应用是否打开无关

到点时若有到期词提示「该复习了」，没有到期词但有新词额度则提示学习任务；同一时段一天只提醒一次。

## 建议的学习节奏

先做一次水平自测，再看「备考计划」里的第 1 周。没有测评时的通用节奏：

1. **第 1–2 周**：每天 20–30 个新词 + 1 组听力，把耳朵和词汇量打开
2. **第 3–4 周**：每天 1 篇阅读 + 1 句翻译，重点练定位与同义替换
3. **第 5 周**：每天 1 篇写作，先写再看范文，把范句抄一遍
4. **第 6 周**：只做复习，清空词汇复习队列，重做错得最多的阅读

目标 500+ 的话建议每天 90 分钟（计划页有平日 / 周末 / 保底三套时间表），任务清单里的四项打完卡只是下限。每两周复测一次，看曲线比看单次分数更有意义。

## 数据

所有进度存在浏览器 `localStorage`（键名 `cet6_trainer_v1`）。

- 换浏览器、清缓存、无痕窗口都会看不到旧进度
- 可在「设置 → 导出学习记录」下载 JSON 备份
- 设置里也能修改每日新词目标、每日时长、考试日期与朗读语速

## 扩展题库

新增单词时往 `data-vocab.js` 的数组里追加，字段保持一致：

```js
{ w: "单词", ph: "/音标/", pos: "v.", cn: "释义", tag: "主题", ex: "例句", exCn: "例句翻译" }
```

阅读、听力、翻译、写作改 `data-content.js`，测评题改 `data-exam.js`，备考计划改 `data-plan.js`，记忆方法与词根表改 `data-memory.js`，页面会自动读取。

测评题字段：

```js
{ q: "题干", opts: ["A", "B", "C", "D"], ans: 0, exp: "解析" }
```

听力题额外加 `lines: [{ sp: "M", t: "..." }]`（`sp` 取 M / W / N），阅读题额外加 `text` 指向 `texts` 里的文章 id。

## 说明

- 听力语音由浏览器合成，音色取决于系统已安装的英文语音；没有网络或语音包时可能只发出默认读音
- iPhone 的系统通知需要 iOS 16.4+，且必须先在 Safari 里「添加到主屏幕」后从图标打开；不能满足时请用日历提醒，效果相同且更省电
- 测评分数为折算估算，用于定位薄弱项与安排节奏，不等同于考场成绩
- 题库为备考练习材料，题目与解析用于训练方法，不替代官方真题
